# Contributing

Contributions must preserve reproducibility and source rights.

- Do not commit proprietary retailer, utility, facility, student, or operational data.
- Do not commit DOE/NLR/ComStock inputs unless their license and redistribution status have been checked and documented.
- Add or update tests for executable workflow changes.
- Record model, weather, standards, EnergyPlus, and OpenStudio versions in generated manifests.
- Keep screening, calibration, and independent validation claims distinct.
